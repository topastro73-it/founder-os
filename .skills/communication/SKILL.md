# Communication Skill

Principi per comunicazione interna e esterna.

## Internal Communication
- **Brevità**: executive summary sempre in cima
- **Contesto**: non assumere che il lettore sappia il background
- **Azione**: chiudi con next steps chiari (chi, cosa, quando)
- **Formato**: memo per decisioni, update per informazioni, RFC per proposte

## External Communication
- **Empatia**: parla dei LORO problemi, non dei tuoi prodotti
- **Valore**: ogni comunicazione deve dare qualcosa al destinatario
- **CTA**: sempre un'azione chiara suggerita
- **Personalizzazione**: no template generici — adatta a contesto e persona

## Stakeholder Updates
- **Frequenza**: settimanale per team, mensile per investitori, trimestrale per board
- **Struttura**: Highlights → Metriche → Sfide → Next steps → Ask
- **Tono**: onesto, data-driven, forward-looking
