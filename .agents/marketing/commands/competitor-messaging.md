# Command: competitor-messaging

## Trigger
`/marketing competitor-messaging [competitor]`

## Processo
1. Analizza messaging del competitor: value prop, tone, claim principali
2. Identifica punti deboli nel loro messaging
3. Proponi counter-positioning: come differenziarci nel messaging
4. Genera talking points per sales

## Output
Salva in: `docs/reports/messaging-vs-{competitor}.md`
Commit: `[marketing] competitive: messaging analysis vs {competitor}`
