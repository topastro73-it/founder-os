# Command: seo-analysis

## Trigger
`/marketing seo-analysis [topic]`

## Processo
1. Identifica keyword cluster per il topic
2. Mappa intent: informational, navigational, commercial, transactional
3. Proponi content pieces per ogni cluster
4. Suggerisci struttura linking interna
5. Identifica competitor content per le stesse keyword

## Output
Salva in: `docs/reports/seo-{topic}.md`
Commit: `[marketing] seo: analysis for {topic}`
