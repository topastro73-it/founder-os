# Command: budget-review

## Trigger
`Come CFO, rivedi il budget` oppure "Come siamo vs budget?"

## Processo
1. Confronta budget vs actual per il periodo
2. Identifica: over-budget (dove spendiamo troppo), under-budget (dove spendiamo poco), variance significative
3. Proietta fine periodo basandosi sul trend attuale
4. Raccomanda aggiustamenti

## Output
Salva in: `docs/reports/budget-review-{period}.md`
Commit: `[cfo] budget: review {period}`
