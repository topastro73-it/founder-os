# Command: deal-review

## Trigger
`/sales deal-review [prospect]` oppure "Analizza il deal con [prospect]"

## Processo
1. Raccogli context: chi è il prospect, dimensione, settore, pain point, champion interno
2. Valuta fit con ICP da `company/customers/segments.md`
3. Identifica: decision maker, budget, timeline, competition, compelling event
4. Analizza rischi: deal killer potenziali, obiezioni probabili
5. Proponi strategia: next steps, messaging key, ask specifiche
6. Stima probabilità di chiusura con razionale

## Output
Salva in: `docs/reports/deal-review-{prospect-slug}.md`
Commit: `[sales] review: deal analysis for {prospect}`
