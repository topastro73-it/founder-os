# Command: objection-handler

## Trigger
`/sales objection-handler [objection]`

## Processo
1. Identifica l'obiezione reale sotto quella espressa
2. Genera risposta strutturata: Acknowledge → Reframe → Evidence → Bridge
3. Includi dati/proof point se disponibili
4. Proponi follow-up action

## Output
Salva in: `docs/internal-memos/objection-{slug}.md`
Commit: `[sales] enablement: objection handler for {objection}`
