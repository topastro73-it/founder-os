# Command: architecture-review

## Trigger
`/cto architecture-review`

## Processo
1. Analizza architettura corrente o proposta
2. Valuta: scalabilità, reliability, security, mantenibilità, costi
3. Identifica single points of failure
4. Proponi miglioramenti prioritizzati
5. Stima effort per ogni miglioramento

## Output
Salva in: `docs/reports/arch-review-{YYYY-MM-DD}.md`
Commit: `[cto] review: architecture analysis`
