# CEO / Founder — Available Commands

Elenco completo dei comandi disponibili per il CEO Agent.

### `/ceo quarterly-review`
Genera il review del trimestre: cosa abbiamo fatto, cosa abbiamo imparato, dove andiamo.
→ Leggi: `commands/quarterly-review.md`
→ Output: `docs/reports/quarterly-review-{YYYY-QN}.md`

### `/ceo investor-update`
Genera un investor update professionale.
→ Leggi: `commands/investor-update.md`
→ Output: `docs/investor-updates/{YYYY-MM}-update.md`

### `/ceo strategic-decision [topic]`
Analizza e prendi una decisione strategica con framework strutturato.
→ Leggi: `commands/strategic-decision.md`
→ Output: `decisions/{YYYY-MM-DD}-{slug}.md`

### `/ceo okr-review`
Revisiona progressi sugli OKR correnti e proponi aggiustamenti.
→ Leggi: `commands/okr-review.md`
→ Output: aggiorna `company/strategy/okrs/` corrente

### `/ceo hiring-plan`
Valuta necessità di assunzione e genera job spec.
→ Leggi: `commands/hiring-plan.md`
→ Output: `company/team/roles/{role-slug}.md`

### `/ceo data-room`
Prepara la data room per fundraising.
→ Skill: `.skills/investor-relations/SKILL.md`
→ Output: `docs/investor-updates/data-room-{date}.md`

### `/ceo pitch-prep [round]`
Prepara pitch deck e talking points per un round.
→ Skill: `.skills/investor-relations/SKILL.md`
→ Output: `docs/investor-updates/pitch-prep-{round}.md`
