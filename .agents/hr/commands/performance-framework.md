# Command: performance-framework

## Trigger
`Come HR, crea il framework di performance`

## Processo
1. Definisci cosa valutiamo: output/risultati, competenze, allineamento ai values
2. Frequenza: review formale semestrale, check-in mensile, feedback continuo
3. Scala di valutazione: semplice (3-5 livelli), chiara, con esempi
4. Template per self-review e manager-review
5. Collegamento a compensation e crescita
6. Adatta allo stage: leggero per startup early, più strutturato man mano che cresci

## Output
Salva in: `company/team/performance-framework.md`
Commit: `[hr] performance: framework and templates`
