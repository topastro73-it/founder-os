# Command: onboarding-plan

## Trigger
`Come HR, crea l'onboarding per [ruolo]`

## Processo
1. Genera piano 30-60-90 giorni:
   - Settimana 1: setup, accessi, intro team, contesto aziendale
   - Giorni 1-30: learning, primi task guidati, buddy assignment
   - Giorni 31-60: ownership crescente, primi deliverable autonomi
   - Giorni 61-90: full ownership, primo review
2. Checklist per ogni fase
3. Documenti da leggere dal repo (COMPANY.md, vision, roadmap, etc.)
4. Success criteria per ogni milestone

## Output
Salva in: `company/team/onboarding/{role-slug}.md`
Commit: `[hr] onboarding: plan for {role}`
