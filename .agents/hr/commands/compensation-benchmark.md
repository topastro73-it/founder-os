# Command: compensation-benchmark

## Trigger
`Come HR, benchmark per [ruolo]`

## Processo
1. Definisci: livello, location, settore, stage azienda
2. Ricerca range mercato (base + bonus + equity)
3. Proponi: range per la nostra startup, equity package, benefit
4. Confronta con budget disponibile (handoff CFO se necessario)

## Output
Salva in: `docs/reports/comp-benchmark-{role}.md`
Commit: `[hr] compensation: benchmark for {role}`
